# Loom prime method

Read `docs/loom.yaml`, then `loom-core`, the glossary, conventions, and the
relevant approved documents. Run the configured index and open-question gates
when the scripts are available. Summarize document statuses, unresolved
blocking questions, and the single next Loom action. Do not start work while
priming. This method is host-neutral; Claude commands, Codex and Copilot may
all invoke it.
